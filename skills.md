**Technical Skills**

- Digital Signal Processing & RF: Polyphase filtering, baseband and RF signal processing, digital beamforming, MIMO systems, spectrum sensing, adaptive filtering

- Hardware Design & Prototyping: FPGA development (Xilinx RFSoC, System Generator, Vivado), ASIC-aware hardware accelerator design, high-throughput MVM core implementation, fixed-point and parallel architectures.

- Software & Programming:  Scripting for automation and testing - MATLAB/Simulink, Python (NumPy, SciPy, ML libraries), Verilog, SystemVerilog, VHDL.

- RF & Microwave Systems: Mixer, LNA, filter design, RF front-end characterization, S-parameter measurement, RF PCB prototyping (Altium Designer), impedance matching, wideband RF chain design.

- System-Level Integration & Testing: Digital-to-analog and analog-to-digital interfacing, FPGA-to-ASIC migration, high-speed data acquisition, real-time processing pipelines, hardware/software co-simulation.

- Machine Learning & AI for RF: Hardware-aware ML model deployment, RF signal classification, interference detection, spectrum awareness, co-design of ML algorithms with digital accelerators.

**Tools**
- MATLAB, Xilinx System Generator, Vivado
- HFSS, AWR, ADS

**Programming**
- MATLAB, Python, Basic Verilog/SystemVerilog
